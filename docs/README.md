# Documentation Map

This folder keeps public review material, product notes, and release checklists
for Pulse Revoke. Start with the short list below when reviewing trust
boundaries or deciding whether to use the app.

## Essential Review Documents

- [Public review guide](PUBLIC_REVIEW_GUIDE.md): entry point for reviewers who
  want to inspect the trust-critical code paths.
- [Security policy](../SECURITY.md): supported write scope, user safety rules,
  and vulnerability reporting.
- [Security notes](SECURITY.md): implementation principles for read and write
  separation.
- [Transparency notes](TRANSPARENCY.md): what the app does, what it does not
  do, and known limitations.
- [Architecture](ARCHITECTURE.md): high-level route, scanner, and wallet flow
  structure.
- [Environment](ENVIRONMENT.md): runtime configuration and secret-handling
  expectations.
- [Audit guide](AUDIT-GUIDE.md): suggested manual review flow.
