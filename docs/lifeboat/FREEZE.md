# Wallet Lifeboat Freeze

Wallet Lifeboat is frozen and unpublished on `main`.

The feature must remain unavailable until the owner explicitly reopens it with
a new scoped phase, review window, and validation plan. The current lock keeps
the public page and `/api/lifeboat/*` routes unpublished on `main`.

The long-term specs in this folder are retained as historical planning and
safety-boundary material only. They are not active product promises.

Do not add new Wallet Lifeboat UI, routes, API calls, smoke commands, or
release checks while this freeze is in place.
